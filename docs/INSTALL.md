# TEa.G3-studio Android installation

## Requirements
- Flutter stable SDK
- Android Studio and Android SDK
- Python 3 (used by the platform configuration script)

## Generate and configure Android
From the repository root:

```bash
bash tool/configure_platforms.sh
flutter analyze --fatal-infos
flutter test
flutter run
```

The script runs Flutter's official Android project generator, then applies:
- App display name: `TEa.G3-studio`
- Android application ID: `com.teag3.studio`
- Minimum Android API: 23
- AndroidX Media3 Transformer: `1.11.1`

The generated native Android project contains a MethodChannel bridge for single-clip trimming and MP4 export. Export files are currently stored in the app's private documents directory.

## Build Android
```bash
flutter build apk --release
```

GitHub Actions performs the same checks and uploads the release APK as a build artifact. A Play Store release additionally requires a private upload key and protected signing configuration; those secrets must not be committed.

iOS is intentionally deferred and is not generated by this setup script.
